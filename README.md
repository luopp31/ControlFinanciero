# Greedy

Control financiero personal (PWA). React + TypeScript + Vite; datos locales en IndexedDB con sincronización opcional a Supabase.

```
npm install
npm run dev     # desarrollo
npm test        # vitest
npm run build
```

Copia `.env.example` a `.env` con tu URL y clave de Supabase. Esquema en `supabase/migrations/` (corre 001 → 003 en orden).
